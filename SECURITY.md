# Security

Lamassu is pre-alpha and has not received an independent security audit. Do not expose its database or future APIs to the public internet. The current CLI stores plaintext, opens no network listener, and does not execute archive content. File size limits and format checks are resource controls, not a sandbox.

Report vulnerabilities using this repository's private vulnerability reporting facility if the maintainer has enabled it. If unavailable, open a public issue asking for a private reporting channel, without exploit details, secrets, personal records, or sensitive code. A dedicated reporting channel and response commitments are pending before any hosted release.

Only the current development revision is maintained. Security reports should include the revision, synthetic reproduction, impact, and proposed mitigation where available.
