# Project stewardship

Lamassu is an open-source research project developed by **UpBeam Research**, a subdivision of **UpBeam OY**. The project's designated research address is [research.upbeam.net](https://research.upbeam.net); the source and public development record are maintained at [Autio/lamassu](https://github.com/UpBeam/lamassu).

## Purpose

Investigate durable personal knowledge and agents whose initiative operates within understandable, enforceable boundaries. Publish the design, experiments, limitations, and code as the work develops.

## Development commitments

- Distinguish proposals, implemented features, and verified results.
- Evaluate existing open-source components before adding custom infrastructure.
- Record significant architectural choices and their consequences.
- Keep private deployments and data separate from public development.
- Use reproducible tests and synthetic public examples.
- Preserve portable evidence and human-reviewed knowledge across changes in agent software.

## Ownership and licensing

UpBeam Research is the project attribution, not a separately asserted legal entity. The project remains MIT licensed. Existing copyright notices are preserved; this attribution does not transfer copyright or change third-party licenses.

The repository is maintained in the UpBeam GitHub organization. Website deployment, hosted operation, support commitments, and independent security assessment are separate work.

## Project decisions

Use issues for scoped work and pull requests for reviewable changes as contributors join. Record decisions that affect data formats, permissions, storage, recovery, or external dependencies in `docs/decisions/`. The roadmap expresses development intent rather than delivery dates or product guarantees.
