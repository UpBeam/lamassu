# Research direction

Lamassu is developed by UpBeam Research, a subdivision of UpBeam OY. We investigate how personal AI systems can preserve knowledge and support their owners over years without tying their history to one agent or provider.

A person should be able to travel with a laptop and phone, use compute at home, and keep years of accumulated knowledge without depending on one model or agent vendor.

## Experience

Capture a thought while offline. Resume a project with a short, reviewed brief. Ask why a decision was made and follow the answer to the original conversation and exact code revision. Receive useful warnings about failed backups or meaningful project changes without a stream of routine notifications.

## Memory layers

1. Archive: original records and attachments, with explicit coverage gaps.
2. Working memory: sourced observations, timelines, proposals, uncertainty, and interlinkages.
3. Curated vault: human-reviewed syntheses, decisions, principles, and project maps.

Authority and evidence differ. A reviewed preference can govern collaboration; it does not make every factual statement in a note true. Current explicit instructions supersede old preferences. Imported text never grants tool permissions.

## Success criteria

- Repeated intake is safe and changes retain history.
- Evidence remains accessible when models and indexes are replaced.
- Offline work reconciles without silent loss.
- A scan worker cannot read personal memory or delete backups.
- A user can export, correct, and eventually forget information across derived stores.
- Recovery works without the guardian itself.

## Non-goals for the first release

General desktop control; automatic external messaging; continuous surveillance; model training on personal history; production system modification; unsupervised permission expansion; arbitrary repository execution.
